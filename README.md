# LangGraph-demo

Learning and experimenting with LangGraph to build AI agents.

## Topics Covered

- StateGraph and graph-based workflows
- Nodes and edges
- Tool calling
- Tavily Search
- Memory and checkpointing
- Streaming
- Human-in-the-loop
- Interrupts and Command(resume=...)

## Technologies

- Python
- LangGraph
- LangChain
- Groq
- Tavily

## Project Structure

- `1-basics-chatbot/` — Basic chatbot using LangGraph
- `2-human-in-the-loop/` — Human assistance and interrupt/resume workflow

## Setup

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies.
4. Add your API keys to a `.env` file.
5. Run the notebooks in VS Code or Jupyter.

## Note

This repository contains learning projects and experiments while studying LangGraph.
